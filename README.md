## 운영 규칙
- 기획/스토리보드/실물 레퍼런스/촬영 프롬프트/오디오를 버전 분리한다.
- AI 생성 결과는 자동 승인하지 않는다. 사람 검수 후 `APPROVED` / `LOCKED` 표기.
- 참고 사진 및 생성 프리뷰는 **GitHub 공개 배포 전 저작권·대외 공개 가능 여부 확인**.
- 실제 사업소 내부 화면·절차·비공개 설비정보를 재현하지 않는다.
- 이미지·영상 프롬프트에는 자막을 렌더링하지 않는다. 모든 문구는 후반 편집에서 정확히 삽입한다.
- 타 주제 「마지막 1초」는 별도 후속 콘셉트로 보존하며 이번 영상에 섞지 않는다.
