## 연속감 중대한 결함
1. S01: 세피아 산업 드로잉 → S02: 두꺼운 선화/패널 추출 작업자 → S03: 또 다른 세피아 사실풍 → S04: 이중 노출 리더·납작한 제어실 → S05: 투명한 인물 합성과 평면 벡터 석양. **재질이 하나의 모래판처럼 이어지지 않는다.**
2. S02 수화기를 든 작업자와 벽 거치대를 한 장에서 확인할 수 없음. S03 작업자/밸브 도형 완전 동일성 추가 확인 필요. S04 리더는 S02 남성② 이미지 파생; S05 인물 합성에서 겹침이 심함.
3. S04→S05 얼굴 투명 중첩을 디지털 wipe/blur로 가리더라도 여전히 인물 원화가 다르므로 해결되지 않음.
4. S05 노을과 엔딩 그래픽은 **손으로 밀어 만든 모래가 아니라 벡터/그라데이션**, 재제작 대상. 최종 메시지·AI 사용 고지는 후반 자막으로 분리.
5. S02 V5에 대한 사용자 **편집용 채택은 보존**하지만, 이를 신규 15개 이미지 마스터 품질 승인으로 해석하지 않는다.
6. 현재 S02–S05 **24초 무음** 검토본만 있으며 S01 실제 6초 I2V/전체 음성 포함 30초 최종본은 없음.

## 교정 표준
- 목표: 백라이트 유리판 위, 짙은 모래 입자의 밀도차·불규칙 모서리·실제 손가락 쓸림 흔적이 보이는 1개의 작품 같은 이미지.
- **금지:** 세피아 사진 필터, 벡터 노을/그라데이션, S02 원본 패널 확대, 인물 사진/만화 잘라 붙이기, 반투명 얼굴 중첩, 의미 없이 모래 입자 노이즈만 얹기.
- 가시적 손은 필수 아님. 새 그림 형성에는 **방향성 스윕→0.07–0.14초 윤곽 희미화→드러냄→0.15–0.25초 안정화**. 전체 통상 0.25–0.40초, 감정 엔딩 0.40–0.55초.
- 전화기: 페이지폰 1대·수화기 1개(들고 있으면 빈 거치대)·화면·3×4 키패드·우측 보조함체. 밸브: 동일 V11, 작은 명판, 화면 V11/음성 ‘브이십일’. 
- 영상에 화풍이 변할 때는 모션이 아니라 **원본 프레임 자체를 교체**한 후 전환을 적용한다.
