# 샌드아트 스토리보드 V1 — 〈페이지폰의 고백〉

**총 30.000초 = 6초 × 5씬. 한국어 대사 원문 및 화자 분리 유지.** 모든 화면은 저온 백라이트 모래판의 핸드메이드 샌드아트이며 실제 원전 시설·운전정보를 복제하지 않는다.

| 씬 | 전역 시간 | 핵심 화면 | 소리 및 의미 | 작업상태 |
|---|---|---|---|---|
| S01 | 0–6초 | 실내 벽 고정 페이지폰 **1대**; 호출 후 동일 기기 푸시인, 마지막 작업자 실루엣 | 호출음 → 페이지폰 자기소개 | 이미지 프리비즈 검토 중 |
| S02 | 6–12초 | 남성1→여성1→남성2, **각 별도 컷**으로 전화 응답 | '네, 알겠습니다.' / '확인했습니다.' / '진행하겠습니다.' → 페이지폰 VO | 미제작 |
| S03 | 12–18초 | 같은 현장 남성이 작은 명판 `V11` 밸브 확인→페이지폰 수화기 들고 제안 | 현장 남성: '브이십일 밸브 한 번 더 확인하겠습니다.' | 미제작 |
| S04 | 18–24초 | 제어실 리더가 동일 통신계열 전화에 답하고 고개 끄덕임 | 리더: '오케이. 작업 잠시 멈추고 같이 확인합시다.' / 페이지폰 VO | 미제작 |
| S05 | 24–30초 | **실내 공동 확인(24–27초)** → 별도 석양 원전 전경 엔딩 카드(27–30초) | 페이지폰 VO: '안전문화는, 연결된 목소리에서 시작됩니다.' | 미제작 |

## 씬별 편집 기준

### S01
- 0–0.8초: 호출음, 수화기는 벽 전화기 거치대에 걸려 있음.
- 0.8–3.5초: 페이지폰 VO '안녕하세요. 전 페이지폰입니다.'
- 3.5–5.8초: 페이지폰 VO '제가 자주 듣는 말이요?'
- 이미지 0/3/6초, **같은 전화기 원형을 고정**; 모래 입자·실루엣 정도만 애니메이션.

### S02
- 6–7.2초 남성 직원① 직접 대사.
- 7.3–8.5초 여성 직원 직접 대사 — **여성 한 꼭지**.
- 8.6–9.8초 남성 직원② 직접 대사.
- 9.9–11.9초 페이지폰 VO '그보다 반가운 말이 있죠.'
- 사람끼리 모핑 금지. 수화기를 손에 들었으면 벽 거치대는 비어 있어야 함.

### S03
- 12–14.4초: 밸브 확인 및 페이지폰 수화기를 집는 동작, 말 없음.
- 14.4–17.8초: 직접 대사 '브이십일 밸브 한 번 더 확인하겠습니다.'
- 화면 명판 **`V11` (작은 금속 태그)**. 음성은 특별 지정 발음 **'브이십일'**이며, `V21`로 화면 표기를 바꾸면 안 됨.
- 이전 작업의 형상 연속성 기준: 빨간 원형 핸들, 회색 밸브 몸체, 파란 플랜지, 노란 링, 작은 V11 명판. 샌드아트에서는 색조를 세피아로 변환하더라도 구성과 위치가 일치해야 함.
- 전화기 1대에 수화기 1개. 손에 들면 벽 거치대가 비어 있어야 함.

### S04
- 18–21.9초 리더 **직접 대사** '오케이. 작업 잠시 멈추고 같이 확인합시다.'
- 22–23.9초 페이지폰 **VO** '바로 이런 순간이죠.' 리더는 입을 움직이지 않음.
- 인물/장비가 다른 형태로 전환되거나 영어 자동 음성 발생 시 실패.

### S05
- 24–27초 실내 V11 공동 확인. 현장 직원 A와 리더 B는 S03/S04와 동일 캐릭터 디자인.
- 27초 **편집 컷**: 서로 다른 이미지인 석양 원전 전경 카드. 설비가 야외로 변형되는 모핑 금지.
- 27–30초 3행 카피 편집 합성:
  - 멈춰 말하는 팔로우십
  - 귀 기울이는 리더십
  - 그것이 원자력안전문화입니다.
- 28–30초 AI 활용 제작 고지. 엔딩 페이지폰을 실외에 배치하지 않음.

## 기술 및 제작 윤리
- 모델이 자동 생성한 영어 대사/임의 음성은 사용 금지. 영상은 원칙적으로 무음 생성.
- 실제 운전정보, 비공개 제어실 화면, 특정 원전 실지형 묘사 금지.
- 최종 타임코드는 ElevenLabs 녹음 파일 실제 길이를 분석한 뒤 조정하며 승인 전에는 잠정값.
