# 15개 기준 샌드아트 이미지 마스터 계획 V1

**핵심:** 5씬×3장=15개는 **시각적 앵커** 개념입니다. 화면 변경을 자연스럽게 만드는 전환 프레임·손 또는 손 없이 흐르는 모래·모션은 필요에 따라 추가 생성하며 **15장만 단순 페이드로 연결하는 슬라이드쇼로 제작하지 않습니다.**

## 작업 순서
1. **스타일 기준 3장 M02 / M08 / M14**를 동일한 모래판 재질로 생성해 나란히 검수.
2. 전화기·V11·리더·현장직원 별도 마스터 확보 후 나머지 12장.
3. 모든 15장을 한 장의 컨택트시트로 묶어 감독이 화풍/장비/캐스팅/씬 경계 승인.
4. 기존 V5 사용자 선택 컷은 편집 동선 참고로 유지하되, 최종 이미지는 승인된 마스터로 교체.
5. 실제 음원 길이로 각 씬 6초 큐시트 확정. 30fps, 최종 30초 전체 900프레임.
6. I2V 및 후반 전환은 **손 화면 노출 선택적**, 짧은 모래 스윕/희미화/안정화 필수. 프리비즈=마스터 아님.

## 승인 금지 규칙
- 15 이미지 중 하나라도 일반 벡터/디지털 콜라주이고 기준 샌드 재질과 다르면 `VISUAL_UNITY_FAIL`.
- 별도 생성한 페이지폰·V11·인물 마스터의 좌우 반전/명판 오류/중복 수화기 확인 시 해당 컷 반려.
- S04 리더와 S05 리더가 같은 사람인지 검수 완료 전에 S05 최종 이미지로 LOCK 불가.
- 음성은 페이지폰 VO와 인물 직접 대사 구분, 화면 `V11` 읽기 `브이십일`.
