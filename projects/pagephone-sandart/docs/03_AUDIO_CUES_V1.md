## 파일/타이밍 QC
1. 한국어 대사별 별도 WAV/MP3 생성, 화자별 voice ID 기록.
2. `VOICE_TIMING_REALIZED.csv`에 실제 길이/시작 무음/끝 무음/발음 기입 후 30초 전체 편집 타임라인 재조정.
3. `V11` 태그를 한국어 **'브이십일'**로 읽었는지 사람 검수.
4. 무음 생성 모션에 후반 립싱크가 필요하면 **실제 한국어 녹음**으로만 처리.
5. BGM ducking, 효과음 레벨, 자막 타이밍, 최종 음성 실재 확인.
