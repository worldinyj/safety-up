# 이미지 생성 후 통합 배치 QC — 필수 제작 규칙 V1

**적용 범위:** `projects/pagephone-sandart/` 전 씬 S01~S05. **이미지 생성 직후마다 자동·수동 검수를 한 묶음으로 수행**한다. 여러 이미지를 개별로 보여주고 나중에 프롬프트/오디오를 따로 평가하는 흐름 금지.

## 순서 (반드시 누락 없이)

1. **기준 고정**: 이전 씬 마지막 프레임 / 이번 씬 스토리보드 / 동일 전화기·밸브·인물·세피아 샌드아트 마스터 / 손 개입 연출 / 공식 한국어 대사 큐시트 확보.
2. **일괄 이미지 생성**: 시작·중간·끝 및 전환 비트·필요한 브리지 이미지 각각 독립된 16:9 고화질 원본으로 생성. 스토리보드 여러 컷이 한 이미지에 합쳐 나오면 `REJECT_STORYBOARD_SHEET` 처리. 필요한 경우 프리비즈용으로만 패널 크롭 사용하고 원생성 품질 과장 금지.
3. **이미지 전체 QC**: 픽셀 크기·네이티브 출처, 텍스트/로고/보안 적합성, 손·모래 물성, 조도/색조, 인물/작업복/설비 형상·위치, 수화기 단 1개 및 빈 거치대, V11 명판 크기, 전/후 씬 앵커 픽셀·맥락 연결 검증.
4. **프롬프트 QC**: 씬별 positive/negative, 무음·한국어 후반 대사 원칙, hand-sweep 동작과 길이, 기기 고정, 인물 모핑 금지, 카메라 움직임/컷 분리, 16:9·6초 지정. 이미지에 없는 장비를 프롬프트로만 보완했다고 `PASS` 선언 금지.
5. **오디오·타이밍 QC**: 한국어 정확한 화자·문장·발음, VO와 직접 대사 분리, 타임코드에서 짧은 전환/겹침/공백 탐지. `V11` 화면 표기 / 음성 지정 `브이십일` 검수. WAV/MP3 미생성 시 `TEXT_ONLY` 및 `AUDIO_NOT_TESTED`; 실제 파일이 있으면 음원 길이·발음·입모양·호흡/무음 검사.
6. **기술·인계 QC**: 파일별 SHA256, ZIP CRC/멤버, 매니페스트/검토 시트/원본 링크, 버전/승인 상태/차단 사항. 공개 GitHub엔 보안 검토되지 않은 PNG·영상은 넣지 않고 문서와 해시만 인계.
7. **통합 판정**: 항목마다 `PASS / FAIL / PENDING / NOT_TESTED` 명시. 필수 이미지/시간/연속성 `FAIL`이면 씬 `BATCH_QC_FAIL`로 기록하고 **I2V 생성 불허**. 사람이 이미지/모션/최종본을 별도 승인하기 전 `LOCKED` 표시 금지.

## 샌드아트 고유 기준

- **장면이 새로 그려지거나 지워질 때 화가의 실제 손이 화면에 등장해 모래를 조작해야 한다.** 카메라 푸시인이나 안정적인 정지 그림 동안 손이 항상 나올 필요는 없음.
- **화가 손**(화면 위에서 모래 그림을 그리는 연출)과 **장면 속 작업자 손**(수화기 사용)을 혼동하지 않는다.
- 손 전환 정지 프레임만으로 '움직임 검수 완료' 처리 금지. 실제 I2V 생성 후 모래의 접촉·형성·사라짐 방향을 검수.
- S02처럼 인물 3명+페이지폰 VO에 손 전환 3개를 6초 내 배치할 때 0.1초 전환은 사실상 3프레임이므로 원칙적으로 재설계. 약 0.25~0.40초 가시 전환을 **잠정 목표**로 검토하되 한국어 실측 길이에 따라 조정한다.
- 페이지폰 한 대, 수화기 한 개. 들고 있으면 벽 거치대는 **빈 상태**. 화면 밖 페이지폰 VO일 때 장면 인물 입은 닫아야 함.
- 실제 제작 규격은 30초·1920×1080·30fps, 씬당 6초. 영상 모델 자체 음성 생성 금지, ElevenLabs 녹음은 별도 파일로 합성.

**현재 S02 기준:** `scenes/S02/QC_INTEGRATED_V1.md`. 이 문서는 영상 생성과 음성을 자동 수행하는 도구가 아니라 매 생성마다 적용할 검수 규약이다.
