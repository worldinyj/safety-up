# 샌드아트 통제형 장면전환 표준 V2 · 2026-10-26

**이 문서는 `docs/02_SAND_ART_VISUAL_BIBLE_V1.md`, `docs/05_IMAGE_POSTGEN_BATCH_QC_V1.md` 중 ‘장면 변화마다 화가의 손이 반드시 보여야 한다’는 종전 규칙을 대체합니다.** 기존 문서는 당시 제작 이력으로 보존합니다.

## 원칙

**변환의 자연스러움이 핵심입니다. 화가의 손은 필수가 아닙니다.** 손이 직접 보이는 수작업 전환과, 손이 지나간 것처럼 모래가 한 방향으로 걷히는 무손 전환을 혼합합니다. 모든 이미지 변형 구간은 ‘이전 그림 윤곽 약화 → 짧은 모래 헤이즈/희미화 → 새 그림 드러남 → 안정화’로 통제합니다. 독립된 설비/인물 장면 간에 자동 모핑이나 수화기 증식을 허용하지 않습니다.

## 전환의 해부학

1. **HOLD**: 이전 장면의 핵심 인물/장비가 식별 가능하게 유지.
2. **SWEEP**: 가상의 붓질 방향에 따라 미세한 모래 영역이 이동. 손이 필요하다고 판단한 하이라이트 컷에만 가시적인 작가 손 사용.
3. **HAZE**: 전환 중심부 약 0.07–0.14초 정도 그레인/블러로 윤곽을 잠깐 희미화. 화면 전체의 긴 모호한 디졸브 금지.
4. **REVEAL**: 앞 장면의 윤곽을 지우며 새 장면의 고정 마스터를 점진적으로 드러냄.
5. **SETTLE**: 전환 종료 뒤 약 0.15–0.25초간 모래가 안정화되도록 유지.

기본 전환 총 길이 **0.25–0.40초**, 긴 감정·엔딩 전환에 한해 **0.40–0.55초** 허용. 이 수치는 30fps 기준 약 8–17프레임이며 장면과 한국어 녹음 길이에 따라 조정. 헤이즈는 전환 전체 길이와 별개로 짧아야 합니다.

## 전역 씬 적용

- S01: 전화기 등장에만 초기 그림 그리는 손 가능. 전화기 본체/거치대는 움직이거나 변형되지 않음.
- S02: 남성①→여성→남성②→페이지폰에서 짧은 방향성 스윕, 손은 한두 전환에서만 나타나도 무방. 사용자 편집 채택 V5는 **삭제하지 않음**.
- S03: 페이지폰→V11 점검→수화기 통화, 작은 `V11` 명판, 지정 발음 **‘브이십일’**. 기존 승인 전 영상은 V2 유지.
- S04: 현장 작업자→리더 응답은 0.3~0.4초 통제 스윕. 리더 직접 대사와 페이지폰 오프스크린 VO는 분리. V1 최종 인물 마스터 승인 전.
- S05: 24.18–24.55초 리더→V11 공동 확인 스윕, 26.58–27.12초 석양 강조 스윕. 후자는 총 0.54초 예외. 손은 직접 안 나옴. 이후 3행 자막은 모래 그림 위에 **후반 합성**.

## 이미지 생성 직후 통합 QC

각 씬 완성시 다음이 동일 버전 안에서 함께 검증되어야 합니다: (A) 이미지 원화의 출처/해상도/컬러/전화기·수화기·인물·밸브 불변성; (B) 긍정·금지 I2V 프롬프트가 해당 **실제 이미지**와 일치하는지; (C) 한국어 화자·원문·발음·타임코드 문서; (D) 실제 녹음이 있다면 WAV/MP3 길이·립싱크·음량; (E) 이전 씬 마지막과 현재 첫 프레임 비교; (F) 모든 생성된 실제 영상의 fps/길이/프레임 수/음성 유무 및 전환 전후 프레임 차이.

- 손 이미지가 없어도 **방향성이 있는 모래 흐름 + 순간 헤이즈 + 안정화**면 통과 가능.
- 모래 움직임이 **디지털 디졸브 모의**인지, 실제 수작업 접촉/물리적 애니메이션인지 반드시 구분.
- 프리비즈 통과≠원화 승인≠무음 영상 승인≠음성 승인≠최종 공모전 영상 승인.
- 승인된 부분은 편집 후보로 보존할 수 있으나 다른 미완료 항목을 `PASS`로 바꾸지 않음.
- 사용자의 S02 V5는 `USER_SELECTED_FOR_EDITING`; S03~S05는 개별 감독 검토 대기.

## 음성 원칙

한국어 대사·내레이션·SFX·BGM은 원칙적으로 후반 별도 합성. 음성 파일 없으면 타임코드/문구는 `PASS_TEXT_ONLY`, 음성 싱크는 `NOT_TESTED`. 실제 30초 러닝타임 및 공모전 고지는 별도 최종 QC.
