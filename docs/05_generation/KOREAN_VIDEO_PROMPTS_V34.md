# 그록봇 I2V 한국어 공통 프롬프트 / 음성 큐 연계 V3.4

> 이 문서를 샷 프롬프트의 **가장 우선하는 한국어 음성/동작 규칙**으로 사용. 시점은 `production/audio_cues_v34.json` 및 `docs/04_audio/AUDIO_CUESHEET_V34.md`를 따른다.

## 모든 샷 공통
현실적인 원자력발전소 내부의 가상 산업시설, 사실적인 한국인 작업자, 흰 안전모와 진청색 작업복, 합법적으로 사용할 수 있는 한수원 공식 CI(원본 별도 합성), 동일 기종의 은회색 벽부착형 IP PAGE PHONE, 16:9 실사 시네마틱, 조명 및 인물 연속성 유지. 영상 생성 모델은 **무음 영상만 제작**하고 임의의 음성·영어 대사·영어 내레이션·배경음악을 생성하지 않는다. 화면 속 한국어 자막은 모델에서 생성하지 말고 편집에서 추가한다. 직원 대사에는 실제 ElevenLabs 한국어 녹음에 맞춘 입 모양, 페이지폰 내레이션에는 인물 입 모양 불필요.

## S01 / 00–06
실내 벽면의 실제 모델 IP PAGE PHONE을 천천히 푸시인. 수화기는 벽 거치대에 고정되어 있고 호출음 뒤에 의인화된 페이지폰이 자기소개한다. 이때 **실제 인물은 말하지 않는다**. 화면의 `안녕하세요. 전 페이지폰입니다.`는 후반 편집에서 합성.

## S02 / 06–12
2초 정도씩 **남성 직원 → 여성 직원 한 컷 → 남성 직원**, 서로 다른 사람이 수화기를 들어 실제 한국어로 짧게 업무 응답. **한 기기에 수화기 하나**, 통화자의 손에 있으면 거치대는 빈 상태. 9.9초 이후에는 페이지폰의 해설이므로 직원의 입 움직임을 중단. 형태 변형 없이 장면을 편집 컷으로 연결.

## S03 / 12–18
**밸브 태그는 `V11`**, 작고 자연스러운 금속 명판 크기로만 표시. 시작과 중간과 끝 **같은 밸브, 같은 위치, 같은 색상, 같은 플랜지·배관 구조**. 동일 남성 작업자가 12~13.6초 살펴보다 13.6~14.4초 페이지폰의 수화기를 거치대에서 꺼내 귀에 대고 14.4초부터 **`브이십일 밸브 한 번 더 확인하겠습니다.`**라고 한국어로 말한다. 해당 대사의 입 모양은 인물에게만 적용. 페이지폰 본체 거치대는 반드시 비어 있음. 밸브를 실제 조작하지 않음.

## S04 / 18–24
남성 리더가 가상 제어실 페이지폰 수화기를 귀에 대고 18~21.9초 **`오케이. 작업 잠시 멈추고 같이 확인합시다.`**라고 한국어로 직접 응답. 22~23.9초에는 리더의 입이 닫힌 상태에서 페이지폰의 내레이션 **`바로 이런 순간이죠.`**가 별도 트랙으로 재생. 리더의 표정은 존중과 협력.

## S05 / 24–30
24~27초 두 남성 직원이 같은 실내 V11 밸브를 공동으로 시각 확인. 페이지폰 내레이션 **`안전문화는, 연결된 목소리에서 시작됩니다.`**. 두 직원은 직접 말하지 않아 입 모양 불필요. 27초 편집 컷으로 사용자가 선택한 석양 원전 전경에 전환, 세 줄 엔딩 카피와 AI 제작 고지는 편집 프로그램의 정확한 한국어 텍스트 레이어 사용. **실내가 원전 야외로 변형되는 생성형 모핑 금지**.
