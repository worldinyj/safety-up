# 오디오/나레이션 설계 V2

## 기본 원칙
- Grok Image-to-Video는 가능하면 **무음 생성**; 통화·호출음·AI 의인화 페이지폰 보이스는 후반 합성.
- TTS: **ElevenLabs** (실제 선택 음성 ID/모델은 테스트 검수 후 고정).
- BGM: 사용자가 언급한 **Google Flow 계열 음악 생성** 도구 (정확한 서비스·기능·라이선스 확인 후 기록). 기획 가이드는 라이선스 프리 조건을 자동 보증하지 않는다.
- 첫 0초 **현장 호출 신호 음향** 먼저. 허가된 실기기 원음 또는 유사 제작음 사용. 사고 경보/비상 신호와 혼동 금지.

## BGM
처음 0.8초는 호출음 중심 → S02에 가벼운 호기심 리듬 → S03에 다이내믹 잠시 감소 → S04/05 따뜻한 자신감과 결연함. 사고·위협 스릴러 음악 지양. 말소리 대역 피하도록 EQ/ducking.

## 필수 믹스 검수
1. 페이지폰 호출음은 **목소리보다 먼저**.
2. 21번 밸브 문장과 리더 문장을 줄이거나 바꾸지 않는다.
3. 지정 페이지폰 최종 VO: **“바로 이런 순간이죠. 안전문화는, 연결된 목소리에서 시작됩니다.”** (S04 후반 + S05 앞반에 걸쳐도 **동일 발화로 이어지도록**).
4. 오디오 파일 샘플레이트·peak·loudness·진짜 duration 측정 후 타임라인 재조정. 목표는 명료한 방송·교육 재생; 통화 효과로 지나치게 목소리를 뭉개지 말 것.
5. 보이스 ID와 음원 사용권, AI 사용 내역을 제출 서류에 기록.
