# AUDIO CUE SHEET V1

## 음원 계획
- 페이지폰 내레이션: **ElevenLabs** 한국어 자연스러운 명료한 톤. 차분하고 약간 능청스러운 중성/남성 음색. 지나친 로봇음 금지.
- 직원·리더: 별도 ElevenLabs 보이스 프리셋/실연 오디오. 각기 다른 음색으로 혼동 방지.
- 음악: 사용자가 언급한 **Google Flow Music 계열 도구의 정확한 제품명·이용 라이선스 확인 필요**. 편집용 **대사 없는 30초 instrumental** 제작 권장. 고요한 호출 → 경쾌한 템포 → 짧은 긴장 → 해소.
- 실제 호출음: 현장 모델의 허가된 원음 또는 유사한 라이선스 안전 효과음 사용. 임의 추측한 호출음을 '실제 소리'로 주장하지 않는다.

## 믹싱 QC
- BGM는 대사 아래에서 ducking. 대사 SNR 확보.
- 호출음 이후 장시간 음악만 흐르는 공백 금지.
- 무음 재생에서도 흐름이 이해되는 자막 삽입.
- TTS 실제 길이를 기준으로 **타임코드 최종 재조정**. 시간 때문에 말 빠르게 왜곡 금지.
- 음원별 도구·모델명·버전·이용 조건 기록 후 출품 양식에 표기.
