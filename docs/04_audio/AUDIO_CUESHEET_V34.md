> 30초, 6초 × 5개 샷. 아래 시점은 **ElevenLabs 실제 출력 길이 측정 전의 초안**. 음성 파일 생성·싱크 승인 전 `LOCKED` 처리 금지.

## 화자별 정확한 역할
- **PAGEPHONE / 페이지폰**: 의인화 **내레이션(화면 밖 VO)**. 페이지폰 화면/수화기는 움직일 수 있으나 사람처럼 입을 움직이지 않으며, 통화 중 화면에 보이는 다른 사람의 입도 이때는 닫혀 있어야 함.
- **STAFF_M1/STAFF_F/STAFF_M2**: S02 화면 속 남성·여성·남성 직원이 직접 말함. **한 여성은 정확히 한 꼭지**.
- **FIELD_M**: S03 화면 속 남성 현장 직원이 페이지폰 수화기를 들고 직접 말함.
- **LEADER_M**: S04 화면 속 남성 리더가 직접 말함.
- **FX/AMB/BGM**: 호출음·현장음·음악은 말과 별도 트랙.

## 클립별 6초 촬영·움직임·발화 세부 설계

### S01 00–06초 — 페이지폰 자기소개
- 00.0~00.8: **호출음부터** 들린다. 페이지폰은 실내 벽에 설치, 수화기는 거치대에 걸린 상태.
- 00.8~03.5: 페이지폰 VO `안녕하세요. 전 페이지폰입니다.` 화면 모니터 인사말은 정확한 한국어 편집 합성.
- 03.5~05.8: 페이지폰 VO `제가 자주 듣는 말이요?`.
- 00.5~02.5: 영상 **우측 하단 작은 AI 제작 고지**를 편집에만 추가.
- 인물 직접 대사 없음. 영상 생성 모델의 영어 음성/임의 음성 금지.

### S02 06–12초 — 익숙한 업무 응답
- 06.0~07.2: **남성 직원①** `네, 알겠습니다.` 실제 입 모양.
- 07.3~08.5: **여성 직원 한 꼭지** `확인했습니다.` 실제 입 모양.
- 08.6~09.8: **남성 직원②** `진행하겠습니다.` 실제 입 모양.
- 09.9~11.9: **페이지폰 VO** `그보다 반가운 말이 있죠.`. 마지막 남성의 입은 닫혀 있어야 함.
- 인물 간 변신(morphing) 금지. 2초 안팎의 별도 컷 편집 허용.
- 각 전화기마다 수화기 **한 개**. 사용자가 들고 있으면 거치대가 빈 상태.

### S03 12–18초 — V11 확인 후 재확인 제안
- 12.0~13.6: **V11 표지 작게**, 같은 밸브를 살피는 남성 현장 직원, 말 없음.
- 13.6~14.4: 직원이 페이지폰으로 이동해 **거치대에 있는 유일한 수화기를 들어 귀에 댐**. 자연스러운 수취 동작 필요.
- 14.4~17.8: 직접 말하기/입 모양 일치: **`브이십일 밸브 한 번 더 확인하겠습니다.`**
- 17.8~18.0: 짧은 통화 여운 뒤 S04 리더의 응답으로 연결.
- 15초 중간 프레임이 계속 밸브만 살피는 이미지라면 **비디오 생성 이전에 수정 필요**. 14.4초부터 입을 움직여야 하므로, 15초에는 이미 수화기를 든 모습이어야 함.
- 시각적 설비 표지판은 큰 간판이 아닌 **현실적인 크기의 금속 태그 `V11` 한 개**. 다른 숫자·문자 추가 금지.
- **중요한 표기/발음 차이:** 사용자 최신 지시대로 화면은 `V11`, 한국어 대사는 **`브이십일`**. 화면을 `V21`로 바꾸거나 음성을 `브이십일일`/ `브이십일번`으로 변경 금지. 최종 감독 검수 시 차이를 별도 확인.

### S04 18–24초 — 리더 직접 발화와 페이지폰 해설 분리
- 18.0~21.9: 화면 속 **남성 리더가 직접** 수화기에 대고 말함: `오케이. 작업 잠시 멈추고 같이 확인합시다.`.
- 22.0~23.9: 리더가 말끝을 맺고 고개를 끄덕이는 동안 **페이지폰 내레이션** `바로 이런 순간이죠.` 시작. **이 내레이션에 리더 입 모양을 맞추지 않음**.
- 다음 S05에서 리더가 현장에 도착하는 것은 장면 전환으로 시간 경과를 압축해 표현.

### S05 24–30초 — 함께 확인 → 석양 전경
- 24.0~27.0: 두 남성이 실내 V11 밸브를 **함께 시각 확인**, 직접 대사는 없음. 페이지폰 내레이션 `안전문화는, 연결된 목소리에서 시작됩니다.` 시작.
- 27.0~30.0: 사용자가 확정한 원전 석양 엔딩 컷(내부 설비가 밖으로 변형되는 효과 **금지**). VO는 목표 27.5초까지 마무리될 수 있음.
- 27.0~30.0: 마지막 3행 `멈춰 말하는 팔로우십 / 귀 기울이는 리더십 / 그것이 원자력안전문화입니다.` 편집 합성.
- 28.0~30.0: 오른쪽 아래 **AI 제작 고지**, 가독성 확인. 페이지폰이 야외에 설치된 듯한 연출 금지.
