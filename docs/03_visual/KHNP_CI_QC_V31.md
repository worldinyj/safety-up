# KHNP 공식 CI 정합성 검수 · V3.1 (2026-10-26)

**상태: BRAND_QC_PENDING.** 생성 영상에 등장하는 안전모·가슴패치의 KHNP 유사 로고를 공식 로고로 간주하거나 그대로 `LOCKED` 처리하지 않는다.

## 공식 1차 자료
- 공식 CI 소개 및 **PNG/AI 다운로드**: https://www.khnp.co.kr/main/contents.do?key=2238
- 심볼/한글·영문 로고타입/가로·세로 조합형 제공. **현재 적용 후보는 녹색 사선 심볼 + 청색 KHNP 영문 조합형**.
- 공식 제시 색상: KHNP Green `C90 M0 Y100 K0`, KHNP Blue `C100 M80 Y0 K0`. 웹에서 추정한 임의 HEX로 색상을 고정하지 않는다.
- 회사 공식 자료에 이미지 파일이 공개되어 있어도 모든 외부 공개 사용권이 자동 부여되는 것은 아니다. 대외 활용/공모전 사용 가능 여부 확인.

## 비교한 생성 시안
1. 남성 작업자 + A밸브 + 페이지폰 (사용자에게 전달된 독립 실사풍 시안): 안전모 녹색 심볼 곡률/대각선/청색 영문 비율을 공식 파일과 재대조할 것. `A` 태그는 정확하지만 전화기의 보조함체/버튼/화면 구성은 실물 참조와 불일치함.
2. S02 여성 직원 통화 독립 시안: 안전모와 가슴 패치 심볼 형상이 시안마다 다름; 전화기 모니터에 `7.0` 표기가 남아 있으면 편집에서 교정 필요.
3. AI 모델이 로고/사선/문구를 그려낸 모든 샷: **임의 모양 사용 금지**. 검증하지 않은 브랜드 표기를 확정본으로 등록하지 않음.

## 구현 순서 (표준)
1. 공식 홈페이지에서 **원본 투명 배경 조합형 CI PNG**를 사용 허가 확인 후 다운로드하고 로컬 `assets/brand/KHNP_OFFICIAL_SIGNATURE.png`에 저장. SHA256 기록.
2. 우선 영상 생성은 **로고 없는 빈 안전모/가슴패치**를 기준으로 진행. AI가 만들어낸 유사 로고를 잔존시키지 않음.
3. 각 프레임/샷의 안면·헬멧 곡면과 패치 위치를 마스킹/트래킹한 뒤, **공식 원본 한 번만 합성**. 곡면 자연스러운 원근과 명암 보존.
4. 보조 스크립트 `scripts/apply_official_ci_overlay.py`는 투명 원본과 **인간 승인 좌표**를 받아 기본 퍼스펙티브 합성을 돕는다. 자동 완성/정확성 보증 아님.
5. 200% 확대 정지검수 + 6초 동영상 재생 검수. 심볼/영문/안전모 곡면/가슴패치/반사/가림/움직임 흔들림을 확인.
6. 내부·외부 배포권과 브랜드 담당자 확인 후 `CI_APPROVED`로 전환.

## 사용자 지시 LOCK 유지
밸브 표기는 **A** 한 글자이고 음성은 **“알파 밸브 한 번 더 확인하겠습니다.”**. 여성은 S02 중 1개 몽타주 컷. S05 27–30초는 사용자가 선택한 원전 석양 엔딩.
