# 품질/승인 게이트

| 게이트 | 조건 | 현재 |
|---|---|---|
| G0 BRIEF | 공모 요강·실행 규격 기록 | COMPLETE |
| G1 SCRIPT | 타임코드·대사·자막 길이 인간 승인 | **DRAFT / NOT APPROVED** |
| G2 REFERENCE | 실물 페이지폰 충실도, 권리·공개 여부 확인 | **PENDING** |
| G3 KEYFRAMES | 16:9 **개별 장면** 원본 3장 이상, 실물 일관성 확인 | **NOT LOCKED** |
| G4 I2V | 6초 영상 × 5개, 움직임·연속성·PPE 확인 | NOT STARTED |
| G5 AUDIO | 호출음→대사→VO→BGM 믹싱, 대사 길이 확인 | NOT STARTED |
| G6 EDIT | 30초 FHD MP4, 500MB 이하, start/end AI 안내, 3행 엔딩 | NOT STARTED |
| G7 FINAL | 내부 보안·저작권·사용조건·영상 human accept | NOT STARTED |

## 평가
- 형식: 1920×1080 / MP4 / 16:9 / 30s / <500MB.
- 처음 0초에 호출음이 나온 후 통화 시작하는가.
- 시작 AI 고지 **우측 하단** 작게 등장·소멸, 종료 고지 포함.
- 사용자가 지정한 정확한 3개 대사 보존.
- 엔딩에 정확히 **팔로우십 / 리더십 / 원자력안전문화**.
- 비상/사고 과장/비공개 설비 노출 없이 현장 직원이 공감하는가.
- 생성한 콘셉트 시트(5장면 포스터)는 **개별 독립 키프레임으로 승인 불가**.
- 현재 프리뷰 3장은 콘셉트 시트에서 추출·재구성한 **1920×1080 검토용 이미지**일 뿐, 제작용 I2V 입력 마스터로 **사용 금지**.
